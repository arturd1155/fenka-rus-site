# Heritage Library Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate the existing «Наследие ФЕНКА» media library into the main FENKA site at `/media/heritage/`, with an entry point on `/media/`, shared site chrome, preserved media, and working interactions.

**Architecture:** Keep the existing static-site build and extract heritage-specific rendering into a focused CommonJS module consumed by `scripts/build-site.cjs`. Store browser data, behavior, scoped CSS, and thumbnails under `site/heritage/`; the build copies them to `dist/media/heritage/`. The global header/footer remain generated by the main site, while the heritage body uses an isolated dark archive theme.

**Tech Stack:** Node.js CommonJS, static HTML/CSS/JavaScript, Node test runner, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-09-24-heritage-library-integration-design.md`

## Global Constraints

- The public routes are `/media/` and `/media/heritage/`.
- «Наследие ФЕНКА» remains inside «Медиатека» and does not become a global navigation item.
- Existing video metadata, VK embeds, synagogue records, descriptions, and thumbnails are preserved without shortening.
- The library uses the shared FENKA header, mobile menu, footer, contacts, and social links.
- Heritage styles are scoped below `.heritage-page` and must not affect other sections.
- Bootstrap and Bootstrap Icons are not shipped in the integrated page.
- The page supports 320px-wide screens, keyboard focus, Escape-to-close, empty states, and lazy-loaded images.
- Existing untracked audit and migration files remain untouched.

## Review Focus

- A thumbnail path that is missing or contains nested folders must show a stable fallback without breaking the card; Task 3 tests missing-image handling.
- A search query containing mixed case or surrounding spaces must match title and description text; Task 4 tests normalization.
- Opening one media item after another must replace the prior iframe and closing must remove it; Task 4 tests modal cleanup behavior markers and manual verification covers playback.
- The global mobile navigation and heritage modal must coexist without trapping page scroll after Escape; Task 4 tests required controls and the final visual check exercises the sequence.
- A failed or absent collection must render a visible empty state rather than an empty horizontal row; Task 3 tests the renderer output.
