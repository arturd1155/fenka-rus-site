# News Archive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перенести полный архив из 5 493 новостей ФЕНКА в быстрый и читаемый раздел нового сайта.

**Architecture:** Скрипт импорта получает перечень из локальных снимков sitemap, сохраняет нормализованные данные с возможностью продолжения и собирает статические страницы. Отдельный build-hook создаёт каталог, детальные страницы, стили и клиентский поиск/фильтрацию без загрузки тысяч карточек в DOM.

**Tech Stack:** Node.js CommonJS, статические HTML/CSS/JS, node:test.

**Spec:** `docs/superpowers/specs/2026-11-09-news-archive-design.md`

## Global Constraints

- Итоговый перечень содержит ровно 5 493 уникальных URL за 2018–2026 годы.
- В браузере одновременно отображается не более одной порции из 18 карточек.
- Все переходы карточек ведут на внутренние адреса `/news/<slug>/`.
- Импорт можно возобновлять после прерывания.

## Review Focus

- Дублирующиеся slug должны получить стабильный уникальный адрес.
- Пустые или недоступные страницы не должны останавливать весь импорт.
- Отсутствующее изображение должно давать аккуратную фирменную заглушку.
- Поиск должен корректно работать с русским регистром и пустым запросом.
- Очень длинные заголовки и изображения разных пропорций не должны ломать мобильную сетку.
