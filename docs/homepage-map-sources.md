# Карта России в херо

Карта в `homepage-russia-regions.svg` показывает 89 субъектов Российской Федерации в составе, указанном в статье 65 Конституции РФ. Официальный перечень сверяется по публикации Министерства юстиции РФ:

- https://minjust.gov.ru/ru/documents/8011/

В карту включены Республика Крым, Севастополь, Донецкая Народная Республика, Луганская Народная Республика, Запорожская область и Херсонская область.

Геометрия береговой линии и административных границ подготовлена на основе открытых картографических данных GADM / OpenStreetMap и geoBoundaries gbOpen. Для отображения используется равновеликая коническая проекция Альберса. Исходный SVG содержит отдельный подписанный контур для каждого из 89 субъектов; `scripts/verify-homepage-map.cjs` проверяет число уникальных регионов, синхронизацию исходного, анимационного и опубликованного SVG, а также актуальные ключи кэширования.
